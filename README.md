### 🧠 [Multimodal Depression Screening](https://github.com/JavedanCode/multimodal-neuropsych-detection)

**Python · Machine Learning · Research**

A collaborative university research project investigating multimodal approaches to depression screening.

The project explores acoustic and facial features, multimodal fusion, feature selection, and model evaluation using the E-DAIC dataset.

The framework is intended for experimental research rather than clinical diagnosis.
